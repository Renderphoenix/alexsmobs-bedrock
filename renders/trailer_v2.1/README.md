# Alex's Mobs 2 trailer (v2.1)

Final cut: 1920x1080, 60 fps, 97.5 s, rendered with EEVEE (32 samples) from the add-on's own models, textures and
baked animations. The MP4 (66 MB) and the 91 GB of frames live on H:/AlexsMobs2_Trailer; this folder keeps:

- `alexsmobs2_trailer.gif`: 28 s summary of every shot (432 px, under 2 MB), made by `trailer/make_gif.py`.
- `stills/NN_<shot>.png`: the last frame of each shot, in trailer order (made from the 60 fps render).

Music: "Heroic Age" by Kevin MacLeod (incompetech.com), licensed under Creative Commons: By Attribution 4.0.
Original mod: Alex's Mobs by Alexthe666. This is an unofficial Bedrock port.
